# veradnt-llbot

QQNT chat robot by LLBot (Luky LiLia 幸运莉莉娅)

Sunny Verdant Leaves (project owner) would like to make chatbots in QQ more vivid, If possible, and even chatbots with digital life by simulating the dynamic system of human thought processes.

## Project Configuration 项目配置

- **Python**: 3.8+
- **Dependencies**: See `requirements.txt`

```bash
# 1. Create virtual environment 创建虚拟环境
python -m venv venv

# 2. Activate 启用虚拟环境
venv\Scripts\activate           # Windows
source venv/bin/activate        # macOS & Linux

# 3. Install dependencies 安装依赖
pip install -r requirements.txt
```
